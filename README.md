# Mirai MCP server

Official MCP server for the [Mirai](https://satuapps.com) affordable chat completions API.

```bash
npx -y @satuapps/mirai-mcp
```

Guest quota works without a key. Set `MIRAI_API_KEY` for paid calls.

Client configs: [`mcp/README.md`](./mcp/README.md).

This repository is the public source for `@satuapps/mirai-mcp`. No application server code is included.
